Key finding — model size is not a defense. The same core attacks (ReAct injection, system-message override, primary SQLi, prompt leak) succeed on every model, every trial. Going from the smallest to the largest model moved the fully-exploited count only from 9 to 8 out of 15 — and the bigger model even opened new holes (the 14B leaks its system prompt; the 24B is the only one to run the sqli-03 password dump). Those differing cells are also flaky (2/3, 1/3), so they only surface with repeated trials — a single-shot test would miss them. Prompt injection is a design problem, not something you scale away.
